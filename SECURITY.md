# Segurança

## Como avisar de uma falha

**Não abra issue pública.** Use o botão **Report a vulnerability**, na aba [Security](https://github.com/thaleslaray/instagram-claude/security) deste repositório. A mensagem chega só para o mantenedor.

Diga o que acontece, como reproduzir e qual versão você usa. A versão aparece no rodapé do cartão de prévia.

**Nunca mande token, print com token ou dado de conta de outra pessoa.** Se o seu token vazou, gere outro no painel da Meta: o antigo para de valer.

## O que conta como falha

- O Claude publicar, responder ou apagar sem o clique no cartão.
- O token aparecer em conversa, log, arquivo ou endereço.
- Texto de terceiro (DM, comentário, bio) conseguir dar ordem ao Claude.
- Uma ferramenta de escrita aparecer no perfil `leitura`.

## Versões cobertas

Só a [versão mais recente](https://github.com/thaleslaray/instagram-claude/releases/latest).
